# 修改音乐播放逻辑以支持新的后端响应格式

## 问题分析
当前代码从后端响应中提取 `music_id`，但新的后端响应格式返回的是 `music_url`：
```json
{"result": {"content": "...", "music_recommendation": {"music_name": "taylor_swift_style_l", "music_url": "taylor_swift_style_l.ogg", "message": "..."}}}
```

## 修改方案

### 1. 修改 `MusicRandomPlayer.kt`
- **修改回调接口**：将 `OnAnalyzeCompleteListener` 的返回类型从 `musicId: Int?` 改为 `musicUrl: String?`
- **更新 JSON 解析逻辑**：从后端响应中提取 `music_url` 而不是 `music_id`
- **处理嵌套 JSON 结构**：解析 `result.music_recommendation.music_url` 路径

### 2. 修改 `SuixinYitingActivity.kt`
- **更新回调处理**：接收 `musicUrl` 而不是 `musicId`
- **添加 URL 处理逻辑**：将 `music_url` 中的 `.ogg` 后缀去掉，得到资源名称
- **修改音乐查找逻辑**：根据资源名称查找本地音乐，而不是根据 ID

## 实现步骤
1. 修改 `MusicRandomPlayer.kt` 中的 `OnAnalyzeCompleteListener` 接口
2. 更新 `sendImageToBackend` 方法的 JSON 解析逻辑
3. 修改 `SuixinYitingActivity.kt` 中的回调处理代码
4. 添加 URL 转资源名称的处理
5. 根据资源名称查找本地音乐并播放

## 预期效果
点击"随心播放"按钮后，系统会：
1. 调用摄像头拍照
2. 将图片发送到后端分析
3. 从后端响应中提取 `music_url`
4. 根据 `music_url` 查找对应的本地音乐
5. 自动播放找到的音乐
